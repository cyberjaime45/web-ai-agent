# Navigation Flow

## Target Application
- **URL**: https://practicetestautomation.com/
- **Description**: Practice test automation home page

## Steps

1. Navigate to the home page
2. Verify the page title contains "Practice Test Automation"
3. Find and click the link or button that navigates to "Practice" or "Courses"
4. Verify the URL changed from the home page
5. Verify new page content has loaded

## Expected Outcome
- Successfully navigate from the home page to an inner page
- Page content updates reflect the navigation

## Notes
- This flow tests basic navigation without any form interaction
- The agent should identify clickable navigation elements autonomously
